# BlackMiro vs Miro plans — everything free

Source: Miro's public pricing page (Free / Starter $8 / Business $20 / Enterprise), read 2026-11-05.
Rule for BlackMiro: **every feature is free, no plan tiers, no limits.** Sign-in is only needed to
save and to share.

Legend: ✅ in BlackMiro now (free) · 🛠 planned (will be free) · — not applicable / needs AI or a
company server (not planned)

| Miro feature | Miro plan | BlackMiro |

## Toolbar hierarchy (levels below the first menu)

Miro's toolbar is several levels deep, and it is **customisable**: every entry in the "+" Tools panel
has *Pin to toolbar*, and recently used tools appear on the toolbar automatically.

```

├─ Shapes and lines ─► Line · Arrow · Elbow · Block arrow · Rect · Oval · Rhombus · Triangle · Divider
│   └─ More shapes ─► "Diagramming shapes" side panel
│        ├─ Search shapes
│        ├─ Basic shapes (~22: star, hexagon, octagon, cylinder, cross, chevron, braces, speech bubble…) [Apply colors ▾]
│        ├─ Flowchart (~48)  [Apply colors ▾]
│        ├─ Callouts · Your shapes (upload SVG)
│        ├─ Packs: AWS 804 · Azure 702 · VMware 555 · Cisco 282 · Google Cloud 285 · Salesforce 208

├─ Frame ─► Custom · A4 · Letter · 16:9 · 4:3 · 1:1 · Mobile · Tablet · Desktop · Slides · Diagram · Engage · Prototype
```

**Built (2026-11-05):** customisable toolbar with "+" tools panel (search, Pin to toolbar);
Shapes & lines menu (line, arrow, elbow, block arrow, rectangle, rounded, oval, rhombus, triangle,
star, divider, More shapes); shape library panel (search, Apply colors, Basic 19 / Flowchart 25 /
Callouts 5 / Arrows 7); pen panel (pen, highlighter, smart drawing, eraser, precision eraser,
lasso, 3 presets, colours, width); sticky 16 colours + Stack + Bulk add; frame presets (Custom,
A4, Letter, 16:9, 4:3, 1:1, Mobile, Tablet, Desktop); template gallery window with use-case
categories and search; emoji stickers (desktop/Android); icon library (72 hand-drawn icons,
6 categories, search); Layers panel (new, rename, reorder, hide, lock, move selection).
Not yet: technology shape packs (AWS/Azure/UML/BPMN…), uploading your own shape set, GIFs.

Original plan — BlackMiro equivalents to build (free): shape library panel with search, categories and colour
presets (basic, flowchart, callouts, UML, BPMN, ERD, network/cloud-style generic packs, upload SVG);
pen panel (highlighter, eraser, precision eraser, lasso, presets); frame presets; template gallery
window with categories and search; emoji/sticker panel; layers panel; icon library (Font Awesome Free
is CC BY 4.0, so it can be bundled); customisable toolbar with "Pin to toolbar".

## Right-click menus and shortcuts (matched to Miro, 2026-11-06)

**Empty board:** Paste · Select all · Unlock all · Add text / sticky note / comment at the
click point · Start cursor chat (`/`, shown to everyone in a live session) · Set start view
(pick a frame; go to / remove) · Set current view as start · Show grid (`G`) · Show comments ·
Snap to grid · Snap objects (smart guides) · Show object size · Suggest object size ·
Mouse or trackpad (auto / mouse / trackpad) · Show all (`Alt+1`).

**Object(s):** Copy · Copy link (paste it on the board to jump back) · Copy as image
(`Ctrl+Shift+C`) · Duplicate · Delete · Add comment · Scale to original size (images) ·
Add to Saved files · Download (images) · Arrange ▸ (Bring forward `Shift+PgUp`, Bring to front
`PgUp`, Send backward `Shift+PgDn`, Send to back `PgDn`, Move to layer ▸) · Group / Ungroup
(`Ctrl+G` / `Ctrl+Shift+G`) · Link to (web address or frame, `Ctrl+Alt+K`) · Lock
(`Ctrl+Shift+L`) · Create frame · Save as template (appears under "My templates") · Image ▸ ·
More ▸ · Info ▸ (board owner, last modified by + when, created by + when, name with Copy).

**Keyboard (F1 lists them all):** tools V H T N S R O L P E C F, `1`–`9` = toolbar tools in
order, `Tab`/`Shift+Tab` walk objects, `Alt+drag` drags a copy, `Alt+arrows` duplicates
alongside, `Ctrl+drag` moves without snapping, `Ctrl+Backspace` clears text, `Alt+2` zooms to
the selection, arrows pan when nothing is selected.

Not taken from Miro: "Start a Flow" (AI), `D` card, `M` minimap, `Ctrl+K` command palette,
`Ctrl+F` find — those features don't exist in BlackMiro yet.
